# rag-eval-lab

Laborator de evaluare pentru RAG: ce chunk size, ce top-k, cu sau fără reranking, ce embeddings —
justificat cu cifre, nu cu „așa se face”.

Corpus: 12 documente de politici ale unui magazin online fictiv (TechNova, Moldova), în română.

> Lucru în desfășurare — Pasul 3 din planul meu de studiu (RAG serios + evaluare).
